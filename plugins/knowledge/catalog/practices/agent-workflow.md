# エージェントとの作業の進め方

AI のエージェントに作業を任せるときの、進め方の判断。 項目の形は `plugins/knowledge/catalog/README.md`。

### 段階ごとに、強いモデルを要所で使う

| 欄 | 内容 |
| --- | --- |
| ID | `advisor-at-decision-points` |
| 出どころ | Claude Code の文書「Escalate hard decisions with the advisor tool」。https://code.claude.com/docs/en/advisor.md |
| ソース | なし |
| 何を言っているか | 主のモデルが、やり方を決める前、同じエラーが繰り返すとき、完了を宣言する前に、より強いモデルに相談する（いつ相談するかはモデルが決め、規則ではない。プロンプトで相談を頼むことはできる）。相談は会話の全体を読むので説明し直す必要がなく、強いモデルを通しで使うより、ふつうは安い。相談のたびに会話の全体をキャッシュなしで読むので、長いセッションほど 1 回が高い。助言役の入り切りは主のモデルのキャッシュを無効にしないが、モデルの切り替えは無効にする。 |
| 確からしさ | 公式の推奨。実験的な機能と明記され、使える提供元が限られる（Anthropic の API などで使え、Amazon Bedrock などでは使えない）。助言役が主のモデルより下位なら、Claude Code は付けない。誤用: 主が最上位のモデルのセッションで、費用が下がると期待する。短い作業や、すべての手に強いモデルが要る作業で使う。 |
| 当たるべき場面 | `ready` の Issue の作業を始めるとき、どのモデルの組み合わせで進めるかを選ぶとき。長いセッションを続けるか区切るか決めるとき。 |
| 判断の問い | この作業は、ほとんどの手が定型で、計画の質が結果を決める形か。このセッションは 1 Issue に収まっているか。 |
| 対象 | なし |
| 確認 | 2026-11-15 / 間隔 90 日 |
