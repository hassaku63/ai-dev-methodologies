# docs-sync

`docs/dev/docs-hygiene.md` の「自己点検 `docs-sync`」の手順をそのまま実行する。手順の本体はその文書だけに書いてあり、ここには書かない（二重管理を避けるため）。

要点:

1. main に当たるブランチとの差分から、追加・削除・改名した名前（型、関数、ファイル、ディレクトリ、コマンド、設定）を拾う。
2. それぞれを Markdown の文書から逆引きする。
3. 古い記述は直す。経緯の説明は現在形に書き直す。腐る値（数値、日付、「予定」）は削るか、取得するコマンドか Issue に置き換える。
4. `make docs-check` を通す。
5. 直すべき箇所がなければ、その旨を PR 本文に 1 行書く。

サブエージェントに任せる場合は、`docs/dev/docs-hygiene.md` の手順と差分を渡し、「ファイル:行、現状、修正案」の一覧だけを返させる。
