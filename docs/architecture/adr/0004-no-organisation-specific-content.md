# 0004. 会社や組織に固有の情報を置かない

- 日付: 2026-11-15
- 状態: Accepted（所有者の指示）

## 文脈

このリポジトリは公開されている。導入先には会社のリポジトリが含まれるが、会社側の文脈はこのリポジトリに渡せない。それでも、会社で使う技術（CDK、Terraform、ECS、Lambda、Security Hub など）に合う部品は作りたい。

## 決定

1. 会社や組織に固有の規則、構成、識別子、文書への参照を、このリポジトリに置かない。
2. 扱う技術スタックの選択には、会社で使うものを反映してよい。
3. 部品の確認に例が要るときは、架空の例を作り、架空であることを書く。
4. 組織に固有の知識の索引は、導入の途中か直後に、導入先のリポジトリの中で所有者自身が作る。導入の手順がそれを促す。

## 検討した選択肢

- **リポジトリを非公開にして、固有の情報も置く**: 部品を実態に合わせやすい。個人と会社の両方で使う 1 つの場所にできなくなる。

## 結果

- 部品は、実在の環境で確かめないまま作ることになる。実地での確認は、所有者が導入先で行う。
- 導入の手順に、固有の知識を導入先で書かせる段が要る。
