# 0006. Claude Code を既定にし、規則の正典は `AGENTS.md` に置く

- 日付: 2026-11-15
- 状態: Accepted

## 文脈

所有者の既定の道具は Claude Code。私用では Cursor と Codex も使うことがある。道具ごとに規則を書くと、内容がずれる。

## 決定

1. 配る部品は、Claude Code の仕組み（plugin、スキル、サブエージェント、フック、権限の設定）を主にして作る。
2. 導入先の規則の本体は `AGENTS.md` にだけ書く。`CLAUDE.md` は `AGENTS.md` を読み込み、Claude Code に固有の補足だけを持つ。
3. Cursor と Codex への対応は、`AGENTS.md` を読ませることを基本にする。固有の設定の出力は、要るようになってから足す。

## 検討した選択肢

- **道具ごとに同じ規則を生成する**: どの道具でも同じ体験になる。生成物が増え、ずれの検査が要る。

## 結果

- Claude Code 以外では、plugin の手順（スキルやフック）は働かない。規則だけが共有される。
- 出どころのリポジトリと同じ形なので、一般化しやすい。
