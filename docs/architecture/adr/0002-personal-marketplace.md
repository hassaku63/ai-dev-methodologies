# 0002. このリポジトリを個人用のマーケットプレイスにする

- 日付: 2026-11-15
- 状態: Accepted

## 文脈

更新し続ける手順（スキル、サブエージェント、フック）を、複数の導入先に届けたい。使う人は所有者 1 人で、簡単に使えればよい。所有者は、マーケットプレイスにすると全世界に公開されるのではないかと心配していた。

Claude Code の公式の文書（<https://code.claude.com/docs/en/plugin-marketplaces>、2026-11-15 に確認）によると:

- マーケットプレイスは、`.claude-plugin/marketplace.json` を置いた git のリポジトリ。使う人が自分で登録したときだけ使われる。
- 誰でも使える一覧に載るのは、Anthropic のディレクトリに別に申請したときだけ。
- 非公開のリポジトリでも使える。plugin は、同じリポジトリの中の相対パスで指せる。

## 決定

このリポジトリに `.claude-plugin/marketplace.json` を置き、plugin を同じリポジトリの中に持つ。Anthropic のディレクトリには申請しない。

## 検討した選択肢

- **導入先にスキルをコピーする**: 仕組みが要らない。導入先ごとに古くなる（Serokell が雛形から Skills を分けた理由）。
- **手元の `~/.claude/skills` に置く**: 最も簡単。リポジトリごとに選んで有効にできず、クラウドのセッションに届かない。
- **plugin ごとに別のリポジトリにする**: 独立して版を付けられる。1 人で使うには管理が重い。

## 結果

- 導入先は、設定で使う plugin を選んで有効にできる。
- このリポジトリは公開されているので、一覧に載らなくても中身は誰でも読める。ADR-0004 の制約がかかる。
- 再検討の条件: 公開できない内容を配りたくなったとき。非公開のリポジトリに移すか、分ける。
